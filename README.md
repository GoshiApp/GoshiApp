# Goshi

**Open source skill games on Solana. Enter. Play. Win. Leave.**

Short real-time matches where skill decides the result. A 60 second collection minute, then a battle arena. Every match is verifiable: the seed is committed before anybody joins, the prices are frozen per room, and your replay can be re-run in the browser.

- Website: [goshi.app](https://goshi.app)
- Program and game server: [goshi-escrow](https://github.com/GoshiApp/goshi-escrow)
- Website and game client: [goshi-web](https://github.com/GoshiApp/goshi-web)
- Community: [X](https://x.com/GoshiApp) · [Telegram](https://t.me/goshi_official) · [TikTok](https://www.tiktok.com/@goshi.app)

## Take part
Propose a game, an improvement or a fix: open an issue or a discussion in the repositories. Read `CONTRIBUTING.md` first. Security reports go to support@goshi.app, never in a public issue.

Everything is licensed under Apache 2.0. The program has not been audited by an external firm yet and today it runs on Solana devnet with test SOL.
